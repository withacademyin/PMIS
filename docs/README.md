# Hiring Portal Documentation

Welcome to the internal documentation for the Hiring Portal. This directory contains detailed architectural specifications and guidelines for developers working on the codebase.

## Directory Structure

### 🏗️ Architecture & Technical Specs
- [**Frontend Architecture**](frontend_architecture.md): Development guidelines, tech stack breakdown, and component hierarchy for the Next.js frontend.
- [**Backend Parser Architecture**](backend_parser_architecture.md): Explanation of the two-track resume parsing system (Offline Standardizer vs. NLP Context Blob).
- [**Parser Flowchart**](parser_flowchart.md): A visual Mermaid diagram illustrating the step-by-step data flow of candidate resumes through the hybrid parser.

### 🔐 Development Resources
- [**Testing Credentials**](testing_credentials.md): Pre-seeded mock accounts and standard passwords for testing different user roles locally.

### 🗃️ Archives & Assets
- **`assets/`**: Contains static assets and images used in the documentation.
- **`archive/`**: Contains obsolete planning documents, scratchpads, and historical reference material (e.g., `todo.md`, `implementation_plan.md`).
